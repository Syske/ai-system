# Cool College i18n Resource Completeness Standard

## Purpose

Ensure new enum values or fields have corresponding i18n entries in all locale resource files, preventing blank displays or incorrect fallbacks in the frontend.

## Scope

`runtime-release` + Cool College projects + i18n-related changes

## Rules

1. If an enum value serves as an i18n key (e.g., `create_live_course`), it must have an identically-named entry in all `messages*.properties` files.
2. If `content_*` message templates exist, all locale files must be checked as well.
3. Minimum required locale coverage:
   - `messages.properties` (default / English)
   - `messages_zh_CN.properties`
   - `messages_zh_HK.properties`
   - `messages_en_US.properties`
4. Other locales are optional but strongly recommended.

## Verification Method

- Extract all values from Java enums
- Search each properties file for `{value}=` and `content_{value}=`
- Missing entries are flagged as BLOCKER

## Example

```properties
# messages.properties — ✅ present
create_live_course=Create live course

# messages_zh_CN.properties — ❌ missing
# create_live_course=创建企微直播课
```
